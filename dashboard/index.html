Confusion matrix, 120 new trips

  • Recall is about 43%: most injected noise stays close to the route.
  • The probability is not a calibrated reliability score.
Noise versus route deviation

A deviation needs 3 or more pings in a row more than 30 m from the route that the model mostly does not flag. No real detours exist in the synthetic data, so zero is correct.

Limitations
  • All data is synthetic. Injected GPS noise is not real route deviation.
  • The matcher is a first-pass sequence-aware method, not a full probabilistic matcher.
  • The hotspot search excludes sections beside bus stops, so it missed 2 of 8 planted zones.
  • Measured trip distance is about 0.6% below route length because the start and end of each trip are not covered.
  • Speeds come from pings 10 to 30 seconds apart.
  • Live tracking and arrival predictions need a real data feed and remain future scope.

This screen shows how a rider could follow a bus on one of these routes. A marker replays a position along the route's real shape. Drag the slider to move it.

  • Shown: route line, bus stops, the slow spots found by the analysis, the distance to the next stop and to the next slow spot.
  • Not shown: real bus positions or arrival times. Those need a live vehicle-position feed from the transit agency, which this project does not have.
  • How it would connect: the replay position would be replaced by positions from that feed, run through the same matching and reliability steps used here.

The marker moves at a fixed demo speed and is not tied to any real bus.
