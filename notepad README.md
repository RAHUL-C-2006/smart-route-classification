# Smart Route Classification

## Overview
Smart Route Classification is a machine learning project focused on classifying routes based on the data and features available in the project dataset.

## Project Structure
- `data/` – Dataset files used by the project.
- `models/` – Saved machine learning models.
- `src/` – Source code for the project.
- `dashboard/` – Dashboard-related files.
- `outputs/` – Generated outputs and results.
- `requirements.txt` – Python dependencies.
- `PROGRESS.md` – Project progress notes.

## Technologies Used
- Python
- Machine Learning
- Data Processing
- Data Visualization
